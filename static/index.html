Checks each router against MikroTik's upgrade server. Install then upgrades only the routers that are out of date — each one downloads the new version and reboots itself to apply it. Routers already current are skipped.

Update RouterBOOT firmware on 0 selected router(s)

RouterBOOT is the board's bootloader firmware, separate from RouterOS. Every RouterOS release ships a matching firmware, but the board keeps running its old one until it's upgraded and rebooted. Update RouterOS first, then use this. Routers whose firmware already matches, and CHR/x86 routers, are skipped.
